# LearnLink: 2026 Linguistic Mastery Platform

LearnLink is a high-dimensional English learning platform designed for schools and students, focusing on the "Precision Protocol" and "Direct Association" methodology.

## Core Features
- **Modular Scenario Lessons**: Real-world scenarios (Airport, Restaurant, etc.) with visual scaffolding.
- **The Fading Strategy**: A three-phase learning approach (Intro, Practice, Mastery) to build intuitive responses.
- **Guru Bahasa AI**: Real-time speech evaluation and feedback.
- **Teacher Resource Hub**: Donation-based access to professional methodology guides and lesson plans.
- **Human-Verified Quality**: Content curated and certified by Master Teachers.

## Tech Stack
- **Frontend**: Next.js 15, React 18, Tailwind CSS
- **UI Components**: ShadCN UI
- **AI Engine**: Genkit with Gemini 1.5 Flash
- **Icons**: Lucide React

## Getting Started
To run the development server:
```bash
npm run dev
```

## Push to Production
The app is optimized for deployment on Vercel or Firebase Hosting.
